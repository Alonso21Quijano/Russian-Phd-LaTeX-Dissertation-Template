\begin{frame}{Карта проходимости пространства}
	\footnotesize
	В качестве базовой модели выбрана \textbf{карта проходимости пространства}: пространство разбивается на двумерную сетку $M$, каждой клетке $m_i$ которой сопоставляется вероятность нахождения препятствия $p(m_i)$.

	\begin{minipage}{0.6\linewidth}
		Основания выбора:
		\begin{itemize}
			\item описывает объекты произвольной геометрии, не требуя их классификации;
			\item явно представляет области, о проходимости которых нет информации;
			\item байесовское обновление сводит учёт данных источника к сложению независимо вычисляемых слагаемых $\Rightarrow$ \textbf{принципиально допускает одновременное обновление несколькими источниками}.
		\end{itemize}
	\end{minipage}
	\begin{minipage}{0.39\linewidth}
		\includegraphics[width=\linewidth]{Presentation/images/map_cells}
	\end{minipage}

	$$l_{t,i} = l_{t-1,i} + \underbrace{\ln\dfrac{p(m_i|z_t, x_t)}{1 - p(m_i|z_t, x_t)}}_{\text{обратная модель наблюдения}} - \; l_{0,i}$$
\end{frame}

\begin{frame}{Метрики оценки качества карты проходимости пространства}
	\footnotesize
	Поэлементные метрики (СКО, коэффициент Жаккара) штрафуют ошибку одинаково независимо от того, где на карте она допущена. Для задачи планирования маршрута это не показательно:

	\begin{figure}
		\centerfloat{
			\hfill
			\subcaptionbox{\fontsize{6}{7}\selectfont Эталонная карта.}{
				\includegraphics[width=0.26\linewidth]{images/bad_metrics_gt.png}}
			\hfill
			\subcaptionbox{\fontsize{6}{7}\selectfont Препятствие дальше эталонного положения.}{%
				\includegraphics[width=0.26\linewidth]{images/bad_metrics_far.png}}
			\hfill
			\subcaptionbox{\fontsize{6}{7}\selectfont Препятствие ближе эталонного положения.}{%
				\includegraphics[width=0.26\linewidth]{images/bad_metrics_close.png}}
			\hfill
		}
	\end{figure}

	Карты б) и в) равны по поэлементным метрикам, но карта б) \textbf{опаснее}. Поэтому основной метрикой выбрана \textbf{PFC-MSE}\footnote{\fontsize{6}{7}\selectfont Horel J.-B. et al. Navigation Oriented Evaluation of Occupancy Grids. --- 2023.}: сравниваются стоимости кратчайших путей от БТС до каждой клетки:

	$$\text{PFC-MSE}(GT, I) = \dfrac{\sum_c w_c||GT_{cost}(c) - I_{cost}(c)||_2}{\sum_c w_c},\quad w_c = p(c = free)$$
\end{frame}

\begin{frame}{Задача проекции визуальных детекций на плоскость движения БТС}
	\begin{minipage}{0.6\linewidth}
	 \fontsize{7}{8}\selectfont
	\textbf{Имея:}
	\begin{itemize}
		\item детекции окружающих транспортных средств (ТС), полученного с камеры БТС в виде обрамляющих рамок с границами параллельными границам изображения: $\{d_0, \dots d_n\}, d_i = \left(u_{min_i}, v_{min_i}, u_{max_i}, v_{max_i}\right) \in \left(\left[0,\dots H-1\right]\times\left[0,\dots, W-1\right]\right)^2$, где $W$, $H$ -- ширина и высота изображения в пикс.,
		\item семантическую сегментацию проезжей части для этого же изображения: $S: \left[0\dots H-1\right]\times\left[0\dots W-1\right] \rightarrow \{0,1\}$,
		\item внутреннюю и внешнюю калибровки камеры,
	\end{itemize}
	\textbf{необходимо оценить} положение окружающих ТС в виде ориентированных ограничивающих рамок на плоскости $OXY$: $\{b_0,\dots, b_n\}, b_i=\left(x_{c,i}, y_{c,i}, \theta_i, w_i, h_i\right)\in\mathbb{R}^2 \times \left[-\pi, \pi\right) \times \mathbb{R}^2$, где $x_{c,i}, y_{c,i}$ -- положение центра рамки на плоскости $OXY$, $\theta_i$ -- угол поворота рамки, $w_i, h_i$ -- ширина и длина рамки.

	Для решения задачи делаются следующие предположения:
	\begin{itemize}
		\item все ТС находятся на проезжей части;
		\item проезжая часть лежит в плоскости $OXY$.
	\end{itemize}
	\end{minipage}
	\begin{minipage}{0.39\linewidth}
		\includegraphics[width=\linewidth]{projection_task}
	\end{minipage}
\end{frame}

\begin{frame}{Алгоритм на основе модели L-Shape. Этап 1: проекция}
    \begin{minipage}{0.5\linewidth}
    	\footnotesize
    	\begin{enumerate}
    		\item Берём $N$ равномерно распределённых точек на нижней границе ограничивающей рамки.
    		\item Каждая точка сдвигается к верху изображения пиксель за пикселем, пока не выйдет за пределы проезжей части.
    		\item Строится выпуклая оболочка полученных точек, которая затем проецируется (центральная проекция) на $OXY$: $\{p_0, \dots p_L\}, p_i=(x_i, y_i)$.
    	\end{enumerate}
    \end{minipage}

	\end{minipage}
\end{frame}

\begin{frame}{Алгоритм на основе модели L-Shape. Этап 2: вписывание в рамку}
	\footnotesize
	\textbf{Дополнительные предположения:} на изображении видны не более двух смежных сторон ТС; смежные стороны ТС ортогональны.

	Оцениваются параметры двух ортогональных прямых $l: y = kx + d_1$ и $l': x = -ky+d_2$, минимизирующие среднеквадратичное отклонение вписываемых точек:

	$$\operatorname*{argmin}_{a}\left(Xa - y \right)^2 \Rightarrow a^* = \left(X^TX\right)^{-1}X^Ty,\quad \text{ESS} = a^{*T}X^TXa - 2 a^{*T}X^Ty - y^Ty$$

	\begin{itemize}
		\item Перебираются все точки разделения $m \in \{1,\dots,N-1\}$ множества вписываемых точек между $l$ и $l'$;
		\item в качестве решения выбирается $a^*$ с наименьшей ESS;
		\item \textbf{предложена реализация} с вычислительной сложностью $O(N)$ за счёт инкрементального пересчёта $X^TX$ и $X^Ty$.
	\end{itemize}
\end{frame}

\begin{frame}{Разделение облака точек на точки земли и препятствий}
	\fontsize{7}{8.5}\selectfont
	\begin{minipage}{0.53\linewidth}
		\begin{itemize}
			\item Поиск плоскости методом RANSAC возвращает к отвергаемому предположению о плоскости, поэтому высота земли восстанавливается \textbf{регрессией на основе гауссовских процессов}.
			\item Ядро Матерна ($\nu = 3/2$) --- лучше аппроксимирует разрывы (стыки проезжей части и тротуаров):
			$$k(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \left(1 + \frac{\sqrt{3} d}{l}\right) \exp\left(-\frac{\sqrt{3} d}{l}\right)$$
			\item Регрессия требует $O(N_t^3)$ операций, поэтому обучающая выборка формируется из усреднённых по вокселям координат (несколько сотен точек).
			\item Порог отнесения точки к земле зависит от расстояния до БТС: $z_{thr} = f(||(x_l, y_l)||_2)$.
		\end{itemize}

\begin{frame}{Алгоритм проекции визуальных детекций на основе комплексирования данных камеры и лидаров}
    \fontsize{7}{8}\selectfont
	\IncMargin{2em}
	\begin{algorithm}[H]
		\LinesNumbered
		\KwIn{$I$ -- изображение с RGB-камеры, $P$ -- облако точек.}
		\KwOut{$b_i$ -- ориентированные ограничивающие рамки на виде сверху окружающих БТС объектов.}
		Произвести поиск двумерных детекций объектов на $I$: $\{d_1,\dots d_n\}$\;
		Выделить в облаке точек $P$ точки, не принадлежащие поверхности земли: $P_o$\;
		Кластеризовать полученное облако точек $P_o$ с расстоянием Евклида\;
		Спроецировать все кластеры на изображение $I$: $C_i \rightarrow \widehat{C}_i$\;
		Для каждого спроецированного кластера найти ограничивающую рамку минимального размера: $d_{C_i}$\;
		Используя венгерский алгоритм найти наилучшее сопоставление $d_i$ с $d_{C_i}$\;
		В оставшихся кластерах удалить точки, не попадающие при проекции в сопоставленную детекцию $d_i$: $C_i \rightarrow C^-_i$\;
		\ForEach{$C^-_i$}{
			Используя RANSAC (RANdom SAmple Consensus) найти прямую $l_i$ в $C^-_i$\;
			Построить ограничивающую рамку $b_i$, со сторонами параллельными $l_i$ и ортогональной ей $l'_i$\;
		}
		\Return{$\{b_i\}$}
	\end{algorithm}
\end{frame}

\begin{frame}{Алгоритм проекции сегментации проезжей части на плоскость движения БТС}
	\begin{minipage}{0.6\linewidth}
	\fontsize{6}{7}\selectfont
	\IncMargin{2em}
	\begin{algorithm}[H]
		\LinesNumbered
		\KwIn{$S_I$ -- семантическая сегментация; $\text{res}$ -- разрешение итоговой проекции [элементов/м]; $l$ -- ширина и высота проекции [м]; $z(x,y)$ -- высота поверхности движения}
		\KwOut{$S_{BEV}$ -- проекция сегментации проезжей части на плоскость движения}
		$s \leftarrow \frac{1}{\text{res}}$ \;
		$L \leftarrow l \cdot \text{res}$ \;
		$S_{BEV} \leftarrow $ матрица размера $L\times L$\;
		\For{$i \leftarrow 0$ \KwTo $L$}{
			\For{$j \leftarrow 0$ \KwTo $L$}{
				$x \leftarrow -\dfrac{l}{2} + js$\;
				$y \leftarrow -\dfrac{l}{2} + is$\;
				$(u;v) \leftarrow$ проекция $(x,y, \underline{\textbf{z(x,y)}})$ на изображение\;
				\eIf{$(u,v)$ попадает на изображение И $S_I[u][v] ==$ <<свободно>>}{
					$S_{BEV}[i][j] \leftarrow$ <<свободно>>\;
				}{
					$S_{BEV}[i][j] \leftarrow$ <<неизвестно>>\;
				}
			}
		}
		\Return{$S_{BEV}$}\;
	\end{algorithm}
	\end{minipage}

	\end{minipage}
\end{frame}

\begin{frame}{Комплексирование проекции с базовой картой проходимости пространства}
	\footnotesize
	Проекция не является самостоятельной моделью: сведений о препятствиях в ней нет. Она объединяется с картой базового лидарного алгоритма:

	\begin{itemize}
		\item элементы <<свободно>> $\rightarrow l^c_+$;
		\item элементы <<занято>> либо <<неизвестно>> в поле зрения камеры $\rightarrow l^c_-$;
		\item остальные элементы $\rightarrow 0$; карты складываются байесовским обновлением.
	\end{itemize}

	Расхождение источников переводит элемент в состояние <<неизвестно>>:
	$$l^c_- + l^b_+ \in (-l_t, l_t)$$

	\vfill
	\textbf{Два типа комплексирования в одном алгоритме:}
	\begin{itemize}
		\item \textbf{кооперативное} при проецировании: лидар --- геометрия поверхности, камера --- семантика;
		\item \textbf{конкурирующее} при объединении карт: оба источника оценивают проходимость элемента.
	\end{itemize}
\end{frame}

\begin{frame}{Принцип построения карты проходимости пространства}
	\footnotesize
	\begin{itemize}
		\item По измерениям каждого датчика в отдельном потоке выполнения строится фрагмент карты, хранящий значения $l_+$, которые необходимо добавить на итоговую карту;
		\item фрагменты складываются в очередь;
		\item в отдельном потоке выполнения фрагменты извлекаются из очереди и добавляются на карту.
	\end{itemize}
