\begin{frame}{Беспилотные транспортные средства}
	Последние десятилетия характеризуются активным внедрением и распро­странением беспилотных транспортных средств (далее \textbf{БТС}) в различных сферах человеческой деятельности. Примеры таких сфер:
		\begin{itemize}
			\item логистика,
			\item сельское хозяйство,
			\item горное дело,
			\item городская инфраструктура.

\begin{frame}{Модель окружающего пространства}
	Для осуществления успешного планирования безопасного маршрута БТС требуется \textbf{модель окружающего пространства}. В зависимости от выполняемых задач к данным моделям предъявляются различные требо­вания:
	\begin{itemize}
		\item степень детализации описания окружающего пространства,
		\item вычислительная сложность построения модели,
		\item количество памяти вычислителя, занимаемого моделью и алгоритмами её построения
	\end{itemize}
\end{frame}

\begin{frame}{Комплексирование данных}
	\begin{itemize}
		\item Использование нескольких датчиков разных типов на одном БТС позволяет компенсировать недостатки отдель­ных датчиков и добиться повышения качества создаваемой модели.
		\item В робототехнике задача объединения данных для  определения текущего состояния объекта получила название \textbf{задачи комплексирования данных}.
		\item Наблюдается тренд на увеличение количества датчиков на БТС, для повышения точности создаваемой модели окружающего пространства\footnote{Guerrero-Ibáñez J., Zeadally S., Contreras-Castillo J. Sensor Technologies for Intelligent Transportation Systems // Sensors. — 2018. }.
		\item Данный тренд создаёт риск увеличения задержек при обновлении модели, что может привести к снижению безопасности при планировании движения БТС.
	\end{itemize}
\end{frame}

\begin{frame}{Цель и задачи исследования}
	\textbf{Цель работы} -- повышение безопасности автономного управления за счёт разработки методов построения моделей окружающего про­странства, которые работают на бортовом вычислителе БТС и используют алгоритмы комплексирования данных о проходимости, динамике объектов в сцене, а также слепых зонах БТС.
	
	Для достижения этой цели были поставлены и решены следующие \textbf{задачи}:
	\begin{itemize}
		\item Исследовать существующие методы построения моделей окружающего пространства TC.
		\item Разработать алгоритм оценки положения объектов в окружающем пространстве БТС.
		\item Разработать алгоритмы комплексирования данных для построения модели окружающего пространства TC.
		\item Разработать комплекс технических средств, обеспечивающий построение модели окружающего пространства TC на основе комплексирования разнородных данных с датчиков, установленных на БТС.
	\end{itemize}
\end{frame}
