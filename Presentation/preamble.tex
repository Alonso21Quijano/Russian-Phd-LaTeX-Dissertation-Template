\begin{frame}{Модель Окружающего Пространства}
	Для планирования безопасного маршрута БТС требуется \textbf{модель окружающего пространства}. В зависимости от практических задач к моделям предъявляются различные требо­вания:
	
	\begin{itemize}
		\item степень детализации описания окружающего пространства,
		\item вычислительная сложность построения модели,
		\item количество памяти вычислителя, занимаемого моделью
	\end{itemize}

\end{frame}

\begin{frame}{Комплексирование данных}
	\begin{itemize}
		\item Использование нескольких датчиков разных типов на одном БТС позволяет компенсировать недостатки отдель­ных датчиков и добиться повышения качества создаваемой модели.
		\item В робототехнике задача объединения данных для  определения текущего состояния объекта получила название \textbf{задачи комплексирования данных}.
		\item Наблюдается тренд на увеличение количества датчиков на БТС, для повышения точности создаваемой модели окружающего пространства\footnote{\footnotesize Guerrero-Ibáñez J., Zeadally S., Contreras-Castillo J. Sensor Technologies for Intelligent Transportation Systems // Sensors. — 2018. }.
		\item Увеличение числа датчиков приводит к увеличению объёма входных данных модели, что может приводить к задержкам их обработки, тем самым снижая безопасность движения БТС.
	\end{itemize}
\end{frame}

\begin{frame}{Цель и задачи исследования}
	\textbf{Цель работы:} разработать методы построения моделей окружающего про­странства, которые работают на бортовом вычислителе БТС и используют алгоритмы комплексирования данных для повышения безопасности автономного управления.
	
	Для достижения этой цели были поставлены и решены следующие \textbf{задачи}:
	\begin{itemize}
		\item Провести обзор существующих методов построения моделей окружающего пространства TC.
		\item Разработать алгоритмы оценки положения объектов в окружающем пространстве БТС, а также областей проезжей части доступных для движения БТС.
		\item Разработать программный комплекс, обеспечивающий построение модели окружающего пространства TC на основе комплексирования разнородных данных с бортовых датчиков БТС.
		\item Разработать параллельный алгоритм построения модели окружающего пространства, осуществляющий одновременное обновление модели несколькими источниками данных БТС. 
	\end{itemize}
\end{frame}

\begin{frame}
    \frametitle{Положения, выносимые на защиту}
    \scriptsize
    \begin{itemize} % https://tex.stackexchange.com/a/476052/104425
    	\item Предложенный алгоритм  оценки положения объектов в окружающем пространстве БТС по изображению с монокулярной камеры позволяет на $2.7\%$ увеличить коэффициент Жаккара по сравнению с лучшим из сравниваемых алгоритмов.
    	\item Предложенный алгоритм комплексирования данных с изображения и облака точек лазерного дальномера для проекции визуальных детекций на изображении на плоскость движения БTC позволяет на 33\% увеличить коэффициент Жаккара.
    	\item  Предложенный алгоритм комплексирования данных с изображения и облака точек лазерного дальномера для проекции визуальных детекций на изображении на плоскость движения БTC позволяет на 120\% увеличить дальность до детектируемых препятствий по сравнению с алгоритмом, использующим только визуальные данные
    	\item  Предложенный алгоритм комплексирования данных с изображения и облака точек лазерного дальномера для проекции семантической сегментации проезжей части на изображении на плоскость движения БTC при сочетании с базовым методом построения карты проходимости пространства повышает качество создаваемой модели: на $5\%$ снижает среднеквадратичную ошибку от эталонной карты проходимости пространства и на $9.7\%$ снижает среднеквадратичную ошибку стоимости поиска пути (PathFinding Cost Mean Squared Error, PFC-MSE).
    	\item Предложенный метод построения модели окружающего пространства позволяет в $13.89$ раз уменьшить время обновления карты несколькими датчиками за один цикл получения данных в одномерном случае.
    \end{itemize}
\end{frame}
